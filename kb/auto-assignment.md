# Troubleshooting Auto Assignment Issues
When agents do not receive auto-assigned cases while marked Available:
1. Check for scheduled maintenance or outages.
2. Review queue configuration and assignment rules for conflicting filters.
3. Toggle availability off and on, or clear the session cache.
4. Check system logs for errors such as "no user is present in the specified time".
5. If problems persist, send logs and error messages to your system administrator.
